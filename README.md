# Unlock/Password Reset

A user (Sarah Johnson) submitted a ticket on **Spiceworks** stating that her account was locked after multiple failed login attempts. The tech (Hamed Adams) resolved it by doing the following in **Active Directory Users and Computers (ADUC)** on the domain

- Opened **Find Users, Contacts, and Groups** and searched for "Sarah Johnson."
- Right-clicked her account and selected **Reset Password**
- Set a new temporary password, checked **"User must change password at next logon"** and **"Unlock the user's account."**
- Clicked OK — AD confirmed, **"The password for Sarah Johnson has been changed."**
- The user logged into Windows 11, was prompted to change her password, and successfully signed in
- The tech logged an **internal note** in Spiceworks documenting the action taken, then changed the ticket status from **Open to Closed**
